## 二、核心功能详解

### 2.1 声音克隆

声音克隆是本产品的核心功能。用户上传自己（或目标声音）的音频样本，AI 自动提取声纹特征并训练成可复用的声音模型。

#### 操作步骤

1. **登录账号**：邮箱注册登录 或 使用 Google 或 GitHub 账号一键登录（或游客直接体验 QuickStart）
2. **进入克隆页面**：点击导航栏「声音克隆」
3. **填写模型信息**：
   - 模型名称（必填，需唯一）
   - 选择训练模型类型（推荐选「标准模型 s1」）
   - 模型描述（可选）
4. **上传音频文件**：
   - 支持格式：MP3 / WAV / M4A
   - 文件大小：不超过 50MB
   - 建议时长：5～30 秒，清晰安静的录音效果最佳
5. **填写参考文本**（可选但推荐）：输入音频中说的内容，帮助 AI 更准确学习声音特征
6. **点击「开始训练」**：提交后显示训练进度条，约 10～60 秒完成

#### 训练进度说明

训练过程分为五个阶段，界面实时更新状态：
- 正在上传音频文件
- 正在分析音频特征
- 正在训练声音模型
- 正在优化模型参数
- 正在完成最后处理

训练成功后，模型自动保存至「我的模型」列表，可立即用于文字转语音。

#### 可选训练模型类型

| 模型类型 | 说明 | 适用场景 |
|----------|------|----------|
| 标准，推荐 | 旗舰 40 亿参数，情感丰富 | 日常使用，效果最佳 |
| 轻量 | 推理速度更快，体积小 | 追求速度，对音质要求不高 |
| 高质量 | 最新版本，细节更细腻 | 专业配音、有声书 |
| 兼容 | 稳定版本 | 兼容性优先 |

#### 注意事项

- 音频中背景噪音越少，克隆效果越好
- 建议录音时长 10～20 秒，内容完整、语速自然

### 2.2 文字转语音（TTS）

文字转语音功能允许用户调用已训练好的声音模型，将任意文本内容转换为自然语音。

#### 操作步骤

1. **进入 TTS 页面**：点击导航栏「文字转语音」
2. **选择声音模型**：
   - 下拉列表分为「我的模型」和「预置模型」两类
   - 我的模型：自己训练的克隆声音
   - 预置模型：平台提供的通用声音（无需训练）
3. **输入文本**：在文本框中输入要转换的内容（建议不超过 3000 字符）
4. **设置音频名称**（可选）：留空则自动以文本摘要命名
5. **点击「生成语音」**：等待生成（通常 3～10 秒）
6. **在线播放 / 下载**：生成完成后可直接播放，Pro 用户可下载 MP3

#### 使用技巧

| 技巧 | 详情 |
|------|------|
| 文本长度 | 单次不超过 3000 字符，过长会影响生成速度和自然度 |
| 标点符号 | 合理使用句号、逗号，使语音停顿更自然 |
| 避免特殊字符 | 表情符号、HTML 标签等可能导致生成异常 |
| 数字处理 | 建议将数字写成中文，如「100」写成「一百」，发音更准确 |

---

### 2.3 模型管理

「我的模型」页面提供对所有已创建声音模型的统一管理：

- **查看模型列表**：显示模型名称、训练类型、创建时间、可见性
- **删除模型**：删除后配额释放，可重新创建
- **复用模型**：同一模型可无限次用于 TTS 生成，无需重复训练

### 2.4 首页一键体验（QuickStart）

首页提供无需登录即可体验的「一键生成语音」入口，极大降低体验门槛：

1. 在首页上传一段音频（支持 MP3 / WAV / M4A，建议 5～30 秒）
2. 在文本框输入想生成的内容（最多 500 字）
3. 点击「一键生成语音」
4. 系统自动完成「克隆→TTS」全流程，约 30～60 秒

> **注意**：游客体验有使用次数限制；登录账号后可享受免费版完整配额。

### 2.5 仪表盘与配额管理

登录后可进入「我的仪表盘」查看账号状态：

- **当前套餐**：显示 免费版 / Pro 版 / Pro+ 版

**Q：生成的语音支持哪些格式？**

**Q：可以在商业项目中使用生成的语音吗？**  
A：Pro 及以上版本支持商业用途，免费版生成的内容仅供个人非商业使用，具体请参见平台服务条款。
